# v1.1 内容与教学终审记录

## 目的

这份记录把“自动化结构正确”与“课程负责人认为内容可教、可玩、可发布”分开。自动化通过不能替代中文表达、地域文化、理论因果和游戏时长的人工判断。

## 课程负责人必须逐项确认

在以下表格全部勾选前，不得把内容包标记为“课程正式冻结”：

| 项目                                         | 审查方法                               | 状态 |
| -------------------------------------------- | -------------------------------------- | ---- |
| 12 轮每轮问题能用一句自然中文复述            | 逐轮朗读，并让一名未参与编写者复述     | 待审 |
| 不看理论提示也能理解资源和选择差异           | 只给学生界面，不解释正确答案           | 待审 |

## 终审输出格式

课程负责人完成审查后，将本表的“待审”改为“通过/需修改”，并在下方记录日期、审查人和必须修订的内容。任何内容修订都必须重新运行内容测试、编译检查和发布检查；不能直接覆盖生产历史内容包。

```text
审查人：
日期：
结论：通过 / 需修改
必须修改的 roundId、choiceId 或 eventId：
复测命令：pnpm content:validate && pnpm content:compile && pnpm release:check:v11
```
