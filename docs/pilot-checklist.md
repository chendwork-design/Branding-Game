# 老街品牌局试点清单

这份清单用于 M8 的人工试点，不把游戏分数当作学生理解程度的替代指标。每次测试都记录内容版本、引擎版本、设备、网络、是否首次游玩和匿名 playthrough ID。

## 内部走查

- [ ] 12 个回合标题、目标、人物立场和课程概念与 PRD 一致。
- [ ] 每个选择都有现实诱因、明示收益、顾虑、即时效果、延迟效果、理论映射和报告解释。
- [ ] r08 的视觉方案、店招三秒、手机缩小、同街竞争、包装使用测试均可操作。
- [ ] 报告中的每条结论都能展开到某轮决策、状态变化和理论。
- [ ] 课程负责人核对地域文化表述、专有名词、错别字和幽默事件的现实边界。

## 3–5 人可用性走查

对每位未参与开发的测试者只提供班级码和一句“请独立完成”，不在过程中口头解释。记录：

| 匿名编号 | 设备/浏览器 | 是否无需指导进入 | 是否完成视觉测试 | 是否理解延迟后果 | 报告是否找到因果 | 卡住位置 | 建议 |
| -------- | ----------- | ---------------- | ---------------- | ---------------- | ---------------- | -------- | ---- |
| P-01     |             |                  |                  |                  |                  |          |      |

退出条件：首次进入无需口头指导；没有阻断完成的问题；教师能从后台看到完整时间线。

## 8–12 人平衡测试

记录完成率、中位时长、证据查看率、预测记录、视觉方案分布、结局分布、反思提交率和访谈反馈。重点询问：

- 选项是否像考试题，是否能说出自己的理由；
- 延迟后果是否被感知，还是只看到即时数字；
- 视觉测试是否让人改变选择或形成取舍；
- 幽默是否帮助理解，是否破坏真实品牌经营感；
- 报告是否能解释至少两条“选择 → 机制 → 后果”链条。

目标：中位时长 35–50 分钟；至少 3 条有课堂讨论价值的路径；大多数测试者能从报告解释两条因果链。未达到目标时记录内容调整建议，不能通过降低报告或测试标准解决。

- [ ] 教师总览、学生时间线、匿名案例、四类 CSV 和字段字典均可用。
