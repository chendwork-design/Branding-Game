## 弱网、恢复和数据一致性

- 学生动作先进入本地 outbox，再尝试同步；断网后刷新能够恢复当前轮。
- 服务端只接受动作，按已发布内容重放；客户端提交的指标、结局和报告不会成为正式结算来源。
- 重复动作由幂等键和序号约束拦截；首局与 replay 分离，首局事实不可覆盖。
- 状态快照、证据查看、视觉选择、视觉修订、事件、结局、报告和同步回执均有追加式持久化投影。
- 生产 PostgreSQL 的真实备份恢复演练必须在具备 `pg_dump`、`pg_restore` 和临时数据库的预发布环境执行；当前开发工作区没有这些外部数据库工具，因此这里只验收脚本契约、迁移契约和重放逻辑，未虚构一次线上恢复结果。

## 隐私与安全边界

- 姓名、学号只进入教师授权视图和受保护导出。
- 公共匿名案例、课堂投影、URL、普通日志和分析事件不写入姓名、学号或自由文本。
- 教师后台没有内容、权重、种子、结算、报告或学生历史编辑接口。
- 删除按整班执行；追加式教学记录不提供按学生选择性篡改接口。
- 真实课程上线前由课程负责人确认数据保留期、告知文案和备份清理周期；当前默认建议为 12 个月。
