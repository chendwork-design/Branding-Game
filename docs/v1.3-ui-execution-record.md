## 2. 关键实现文件

- `apps/web/src/v11App.tsx`：学生端 HUD、行动工作区、方案/视觉比较、结果反馈与图标组件。
- `apps/web/src/v11Teacher.tsx`：匿名投影页面标记与投影样式入口。
- `apps/web/src/teacher.tsx`：学生时间线点击后主动刷新，兼容慢设备异步读取。
- `apps/web/src/styles.css`：响应式令牌、三栏/单列布局、移动底栏、视觉工作台、结果反馈与投影样式。
- `apps/web/public/assets/v11/ui-icons.svg`：动作、预算、警示、视觉、结果等统一图标。
- `apps/web/public/legacy-app.js`、`apps/web/public/legacy-app.css`：Vite 开发预览下的经典脚本兼容入口，避免把 HTML 当作 JS/CSS 返回。
- `scripts/check-v11-assets.mjs`：必需资源、单文件和总资源体积检查。
