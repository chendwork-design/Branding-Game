# v1.3.0 内容发布说明

## 发布范围

本版本把扩展后的品牌触点素材库纳入完整的 12 轮经营流程，包括现场问题、决策、视觉测试、阶段结果和结局中的对应素材引用。

## 版本边界

- `v1.2.0` 是已发布的历史内容快照，不能修改其校验和、班级种子或首局记录。
- `v1.3.0` 是本轮视觉触点优化的正式内容快照，沿用 `1.2.0` 规则与报告引擎。
- 新建班级只能绑定 `v1.3.0`；历史班级继续保留其原始版本，不能被升级或覆盖。

## 上线校验

1. Pages 与 Railway `/ready` 必须同时返回 `v1.3.0` 和同一个内容校验和。
2. 教师创建的新班级须显示 `v1.3.0`，且班级码由系统生成。
3. 学生用该新班级码进入后，完成首局、重玩、教师报告与匿名投影均仍沿用服务器记录的版本和种子。
