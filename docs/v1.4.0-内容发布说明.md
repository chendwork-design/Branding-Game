# v1.4.0 内容发布说明

## 发布范围

本版本封存 `COPY-02A`—`COPY-02H` 的文本与流程表达改造：60 个方案使用逐项创作的结果文案，调查结果直接说明事实如何帮助比较，R05 负责视觉说明、R08 负责真实触点测试，结果页与报告按“现场变化—回应—收益—留意事项”组织。

## 版本边界

- `v1.2.0` 与 `v1.3.0` 是已发布的历史内容快照，不能修改其校验和、班级种子或首局记录。
- `v1.4.0` 是本轮游戏文本进阶改造的正式内容快照，沿用 `1.2.0` 规则与报告引擎。
- 新建班级默认绑定 `v1.4.0`；历史班级继续保留原始内容版本，不能被升级或覆盖。
- 本版本不新增回合、方案、角色或结局，不要求组织试玩；人工门禁仅保留逐轮朗读与正式环境检查。

## 已封口的玩家体验问题

- 调查卡显示查完会带回的具体事实，以及它能帮助比较的方案；已调查事实可以回看。
- 结果页不再把正向延迟收益写成风险，也不把同一事实在多个区块重复四次。
- 每轮现场、角色回应、风险与收益均不再依赖统一指标模板；R12 年末现场由本局选择动态生成。
- 术语入口只在本轮确有新概念时出现，并限制主动介绍数量。
- 正式玩家界面不显示内容版本、首局记录、本机进度等后台实现词。
