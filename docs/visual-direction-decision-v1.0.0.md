# 《老街品牌局》视觉方向决策记录

## 评审范围

本方向先服务手机端游戏界面和课程教学反馈，不替代学生最终作业的品牌视觉设计。评审维度为：手机可读性、剧情经营感、地域感、信息层级、后续制作成本。

## 三个候选方向

| 方向           | 视觉关键词                              | 优点                                                     | 风险                                   |
| -------------- | --------------------------------------- | -------------------------------------------------------- | -------------------------------------- |
| A 老街纸本账   | 米白纸张、茶褐、印章、账本卡片          | 经营感强，适合展示“资源—证据—后果”                       | 处理不慎会过度古风                     |
| B 夜市招牌簿   | 深色底、霓虹色、招牌灯箱、即时反馈动效  | 游戏感和即时奖励强                                       | 长文本对比度和课程阅读性压力较大       |
| C 现代茶铺地图 | 米白底、茶褐 + 青黛、地图路径、触点图标 | 可读性、地域感和现代品牌感平衡；适合视觉测试的四触点布局 | 需要约束插画数量，避免界面变成资讯面板 |

## 决策

首版采用 **C 现代茶铺地图**，吸收 A 的纸本卡片和印章式章节编号，不采用 B 的全局深色霓虹。

- 页面容器采用单列阅读流，手机安全区由 CSS `env(safe-area-inset-*)` 保证。
- 资源指标和顾客信号分组显示，避免把玩家资源与消费者结果混成一个分数条。
- 目标卡使用章节编号；反馈卡分成“现在发生 / 先记在账上 / 今天结算”。
- 视觉系统在店招、杯套、包装、头像四个同尺寸触点中比较，不以一张大效果图替代真实使用场景。
- 动效只用于反馈进入、选择确认和结果页；支持 `prefers-reduced-motion`。

## 实施约束

1. 单个核心按钮触控高度不低于 44px。
2. 360px 宽度不出现横向滚动；正文不依赖长句才能操作。
3. 任何关键数值同时给出“对谁有意义”的短说明。
4. 视觉方案比较先看属性与触点，再看名称，避免单纯按“好看”投票。
