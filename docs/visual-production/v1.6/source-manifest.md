# 老街品牌局 v1.6 配图生产记录

## 本次交付范围

本目录记录本轮配图的审核母版、参考来源和部署映射。用户提供的参考图只用于校准屯溪老街建筑、茶饮经营动作、包装材质与版式方向；游戏不会直接复用参考图中的品牌名、LOGO、人物身份或可读文字。

部署资产按“真实场景照片 + 受控状态派生 + SVG 视觉系统”分层：

- 真实生成场景：序章锚点、R01、R03、R07；
- 参考图校准/裁切场景：其余简报、产品、包装、触点和 IP 功能物件；
- 结果页：每个回合由对应简报母图派生 `stable / strained / crisis` 三档，并由界面状态徽标补充明确反馈；
- LOGO、IP 角色轮廓、品牌名和中文正文：仍由 SVG/HTML 叠加，不交给图片模型生成；
- `onboarding-operation.jpg` 是既有运行键的兼容资产，`onboarding-loop-decide.jpg` 使用同一经营动作母图，避免旧内容版本因找不到文件回退到占位图。

## 人工验收结论

- 场景必须能在不看标题时读出“街道、顾客、店内操作或经营压力”；
- 简报图不直接把某个选项拍成标准答案；
- 结果图的三档差异由现场状态、色彩压迫和界面状态徽标共同表达；
- 所有部署图片已统一为 JPG，宽度按场景用途压缩，避免手机端一次加载原始 PNG；
- 生成工具原图已归档在 `docs/visual-production/v1.6/anchors/`，项目运行只读取 `apps/web/public/assets/v11/`。
